# Civix_Group_2
# Civix – Milestone 1 Setup

This README contains everything required to set up and run the **Milestone 1 backend** locally and connect the frontend to it.

## Milestone 1 Backend

Implemented backend features:

- Citizen registration
- Official registration
- Login
- Password hashing using bcrypt
- JWT authentication
- Protected `/me` API
- Role-based authorization
- Input validation
- Duplicate email protection
- User location storage
- MongoDB database connection

---

# 1. Requirements

Install the following before starting:

- Node.js
- npm
- MongoDB Community Server
- MongoDB Compass
- Git
- Postman (recommended for API testing)

Check Node.js:

```bash
node --version
